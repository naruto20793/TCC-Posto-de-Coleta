## 🟡 PROBLEMAS MÉDIOS

### Problema #3: Ordem de CSS quebrada
```
Arquivo: public/consultas/pacientes.html, pacientes.html
Severidade: 🟡 MÉDIA
Localização: <head>

Ordem atual:
1. navbar.css     ← PRIMEIRO (errado!)
2. pacientes.css
3. global.css     ← ÚLTIMO (sobrescreve!)

Ordem correta:
1. global.css     ← PRIMEIRO
2. navbar.css     ← DEPOIS
3. pacientes.css  ← ÚLTIMO

Impacto: global.css pode sobrescrever navbar.css
```

### Problema #4: versão inconsistente de Bootstrap
```
Arquivos com 5.3.0: consultas.html, pacientes.html, cadastro/*
Arquivos com 5.3.2: agendamento.html, login.html, perfil/*

Severidade: 🟡 MÉDIA
Impacto: Pequenas diferenças visuais, incompatibilidades

Recomendação: Padronizar para 5.3.2 em todas as páginas
```

### Problema #5: Script de scroll indefinido
```
Arquivos afetados: 7 arquivos
Severidade: 🟡 MÉDIA (baixa prioridade)

Código:
window.addEventListener('scroll', () => {
    const navbar = document.getElementById('navbarPrincipal');
    document.body.classList.add('scrolled');
    // Classe 'scrolled' nunca é utilizada em navbar.css
});

Impacto: Código desnecessário, sem efeito visual
```

## 🎨 COMPARAÇÃO VISUAL

### ✅ Estrutura CORRETA
```html
<head>
    <meta charset="UTF-8">
    <title>Página</title>
    
    <!-- 1️⃣ Bootstrap primeiro -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css">
    
    <!-- 2️⃣ Font Awesome -->
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css">
    
    <!-- 3️⃣ global.css (projeto) -->
    <link rel="stylesheet" href="../global.css">
    
    <!-- 4️⃣ navbar.css (projeto) -->
    <link rel="stylesheet" href="../assets/navbar.css">
    
    <!-- 5️⃣ Página específica -->
    <link rel="stylesheet" href="pagina.css">
</head>
<body>
    <div id="navbarPlaceholder"></div>
    <main><!-- conteúdo --></main>
    
    <!-- Scripts no final -->
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
    <script src="../assets/navbar.js"></script>
    <script src="pagina.js"></script>
</body>
</html>
```

### ❌ Estrutura INCORRETA (pacientes.html)
```html
<head>
    <meta charset="UTF-8">
    <title>Página</title>
    
    <!-- ❌ Navbar PRIMEIRO (errado) -->
    <link rel="stylesheet" href="../assets/navbar.css">
    
    <!-- ❌ Página específica -->
    <link rel="stylesheet" href="pacientes.css">
    
    <!-- ❌ Global ÚLTIMO (sobrescreve!) -->
    <link rel="stylesheet" href="../global.css">
    
    <!-- ❌ Bootstrap faltando! -->
    <!-- ❌ Font Awesome faltando! -->
</head>
<body>
    <div id="navbarPlaceholder"></div>
    <main><!-- conteúdo --></main>
    
    <!-- ❌ Scripts faltando -->
</body>
</html>
```
